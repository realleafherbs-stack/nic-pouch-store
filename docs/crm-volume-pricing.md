# מדרגות מחיר למוצר ב־CRM

לכל מוצר יש לשמור מערך `priceTiers`. בכל מדרגה:

- `minQuantity` — הכמות המינימלית להפעלת המחיר.
- `unitPrice` — המחיר ליחידה החל מהכמות הזו.

```json
[
  { "minQuantity": 1, "unitPrice": 29 },
  { "minQuantity": 5, "unitPrice": 28 },
  { "minQuantity": 10, "unitPrice": 27 }
]
```

ה־CRM צריך לאפשר עריכת מדרגות לכל מוצר, למנוע כמויות כפולות, לאמת מספרים חיוביים ולהחזיר את `priceTiers` ב־API של המוצר. אם אין הגדרה, האתר מפחית ₪1 ליחידה החל מ־5 ו־₪2 החל מ־10.
